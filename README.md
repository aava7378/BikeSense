# BikeSense

BikeSense is a low-power embedded bicycle sensing system developed for the Low-Power Embedded Design Techniques (LPEDT) course.

The system integrates embedded hardware, sensors, Bluetooth Low Energy communication, and a web interface for bicycle telemetry and monitoring.

## Repository Structure

### `hardware/altium`

Altium Designer project containing the BikeSense schematic, PCB design, component libraries, and related hardware files.

### `ios-app`

iOS application used to communicate with and display data from the BikeSense embedded system.

### `website`

Web application used for displaying BikeSense data and project information.

### `docs`

Project documentation, diagrams, reports, and supporting material.

## System Overview

BikeSense is designed around low-power operation for a bicycle-mounted embedded system. The device collects sensor data, manages multiple energy modes, and communicates using Bluetooth Low Energy while minimizing power consumption.
